# Privacy and publication policy

This public repository intentionally excludes all source papers and real revision cases.

Before contributing, remove or replace:

- names, email addresses, affiliations, ORCID identifiers, grant numbers, and signatures;
- manuscript titles when the work is not already public;
- journal submission numbers, decision letters, and editorial-system metadata;
- verbatim confidential reviewer comments and response letters;
- local usernames, absolute paths, private repository URLs, and commit metadata;
- API keys, tokens, cookies, credentials, and access instructions;
- PDF or DOCX files carrying comments, tracked changes, or document properties.

Use synthetic or independently written examples. A safe example uses fictional labels such as `Author A`, `Reviewer 1`, `Example Journal`, and `<paper-root>/round-1/manuscript.tex`.

Do not assume that deleting a sensitive file from the latest commit removes it from Git history. Audit the complete history before making a formerly private repository public.

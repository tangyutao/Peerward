# Persistent case output schema

Create `case_summary.md` with:

- **Paper Information:** anonymized or public title, field, venue, source path, history mode, and key versions with evidence paths.
- **Initial Problems:** central reviewer concerns and initial weaknesses, separating facts from inference.
- **Revision Actions:** comment, concern and confidence, response strategy, verified change, causal rationale, and remaining limitation.
- **Key Version Nodes:** scientific turning points; diff statistics are supporting metadata only.
- **General Lessons:** 3–10 lessons with trigger, action, rationale, and applicability boundary.
- **Evidence Gaps:** missing or ambiguous evidence.

During intake, a case may contain only Paper Information, a provisional Key Version Nodes section, and Evidence Gaps. Mark the summary `needs_review` until reviewer evidence and response claims have been checked against manuscript changes.

For public or classroom outputs, remove personal data, submission identifiers, confidential quotations, private repository data, and machine-specific paths. Prefer fictional or independently rewritten examples.
